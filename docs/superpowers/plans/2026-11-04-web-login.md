# Web login implementation plan

**Goal:** Replace browser authentication prompts with a styled login page.

**Approved design:** Keep existing credentials and explicit Basic API authentication. Browser users receive an opaque, Secure, HttpOnly, SameSite=Strict cookie. Sessions expire after 12 hours and are revoked on logout, credential changes, or restart. No passwords are stored by JavaScript.

**Architecture:** A bounded in-memory session store supports the existing HTTPS handlers. Public login assets use the existing Vue/Bootstrap stack. Protected pages redirect to login; APIs return 401 without a Basic challenge. Existing CSRF checks remain in place.

**Constraints:** Use apply_patch; document C++ interfaces with Doxygen; change only en localization; preserve unrelated files and submodules.
